# 🤖 Basic Chatbot 

## 📌 Project Overview

This project is a simple **rule-based chatbot** developed using **Python**. The chatbot interacts with users by responding to predefined inputs such as greetings, basic questions, and exit commands.

The chatbot uses simple conditions to match user input with predefined responses, making it a beginner-friendly project to understand chatbot logic and Python fundamentals.

---

## ✨ Features

* Responds to predefined user inputs
* Interactive console-based chat system
* Simple and beginner-friendly chatbot logic
* Exit option using `"bye"` command
* Handles unknown inputs with a default response

---

## 🛠️ Technologies Used

* **Python**

---

## 📚 Concepts Used

* If-Elif Statements
* Functions
* While Loop
* User Input/Output
* String Handling

---

## ▶️ How to Run

1. Open any Python compiler (**online or offline**).
2. Copy and paste the code into the compiler.
3. Click **Run / Execute**.
4. Start chatting with the bot using:

   * `hello`
   * `how are you`
   * `bye`

---

## 🎯 Example Chat

**You:** hello
**Bot:** Hi!

**You:** how are you
**Bot:** I'm fine, thanks!

**You:** bye
**Bot:** Goodbye!
